# LexiBot

Telegram-словарь с карточками и интервальным повторением.

## Запуск через Docker

1. Создайте бота через `@BotFather` и получите токен.
2. Создайте файл настроек:

   ```bash
   cp .env.example .env
   ```

3. В `.env` замените `BOT_TOKEN` и `POSTGRES_PASSWORD`. Значение
   `DATABASE_URL` используется только при локальном запуске без Docker.
4. Запустите PostgreSQL и бота:

   ```bash
   docker compose up -d --build
   ```

Проверить состояние и посмотреть журнал:

```bash
docker compose ps
docker compose logs -f bot
```

Данные PostgreSQL сохраняются в отдельном Docker-томе и не исчезают при
пересборке контейнера.

## Размещение на VPS

Для Ubuntu-сервера достаточно установленного Docker с Compose:

```bash
git clone <адрес-репозитория> lexibot
cd lexibot
cp .env.example .env
nano .env
docker compose up -d --build
```

Порт PostgreSQL наружу не публикуется: база доступна только боту внутри Docker-сети.
Контейнеры автоматически запускаются после перезагрузки сервера и
перезапускаются при сбое.

Обновление приложения:

```bash
git pull
docker compose up -d --build
```

Рекомендуемый минимум для VPS: Ubuntu 24.04, 1 CPU, 1 GB RAM и 10 GB диска.
Для резервной копии базы:

```bash
docker compose exec -T postgres pg_dump -U lexibot lexibot > lexibot-backup.sql
```

## Локальный запуск без Docker

Нужен работающий PostgreSQL, соответствующий `DATABASE_URL` из `.env`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m lexibot
```

## Команды MVP

- `/addnew` — добавить слово пошагово;
- `/addnew word | перевод` — быстрое добавление;
- `/list` — группы и слова пользователя;
- `/study` — повторить карточки, срок которых наступил;
- `/edit` или `/edit word` — изменить слово, перевод или группу;
- `/delete` или `/delete word` — удалить карточку с подтверждением;
- `/cancel` — отменить текущий ввод;
- `/help` — справка.

Во время повторения бот сначала показывает английское слово. Нажмите «Показать ответ», затем оцените воспоминание: «Не помню», «Трудно», «Помню» или «Легко».

После `/start` основные действия также доступны через постоянное меню в нижней
части чата. Во время добавления и редактирования меню заменяется кнопкой отмены.

У карточки пять уровней: новое слово, плохо выучено, хорошо выучено, отлично
(осталось одно повторение) и выучено. Карточки пятого уровня больше не попадают
в сессии `/study`. Интервалы повторения: 15 минут после ошибки, затем 1, 3, 7
и 30 дней по мере успешного изучения.
